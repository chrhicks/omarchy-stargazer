# Changelog

## Unreleased

- Set or change the observing location directly in the panel, using town/postal-code search or manual coordinates.
- Save location settings across restarts without setup commands.

## 0.1.0 — 2026-09-07

First public release.

- Native Omarchy bar widget and themed observing forecast panel.
- Three observing nights with a sliding 24-hour window; drag either chart, step by hour, jump between nights, or return to now.
- Hourly cloud layers, temperature, dew point, wind, gusts, and rain probability from Open-Meteo.
- Calculated Sun/Moon altitude, Moon illumination, and astronomical darkness.
- Illustrative sky responsive to daylight and cloud cover.
- Current-hour tooltip, configurable location and default units, bounded refreshes, and saved-forecast fallback.

In v0.1.0, location setup required plugin settings or the commands documented in that release. In-panel unit switches last for the session. Maps, alerts, seeing/transparency predictions, and precise sky-map rendering are outside this release.
